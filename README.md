# Library

A simple digital library application built as part of **The Odin Project** JavaScript curriculum.

The application allows users to add books to a library, view their books, change their read status, and remove books.

## Features

* Add new books using a form
* Display books as cards
* Store books in a JavaScript array
* Generate a unique ID for every book
* Mark books as **Read** or **Not Read**
* Remove books from the library
* Responsive layout for different screen sizes
* Form validation using HTML
* Modal dialog for adding books

## Built With

* HTML5
* CSS3
* JavaScript
* Git & GitHub

## How to Use

1. Open the application in your browser.
2. Click **New Book**.
3. Enter the book title, author, and number of pages.
4. Select **Read** if you have already read the book.
5. Click **Add Book**.
6. Use **Change Read Status** to update a book's reading status.
7. Use **Remove** to delete a book.
